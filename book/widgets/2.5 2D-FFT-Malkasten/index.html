2D-FFT-Malkasten

Im Bild malen. Im Spektrum filtern. Fourier-Zusammenhänge live entdecken.

Auf beiden Flächen mit Maus, Stift oder Finger malen. Rechtsklick radiert. Gegenfrequenzen werden immer mitbearbeitet.

So funktioniert der Malkasten
  • Bild: Der Pinsel setzt Pixel auf die gewählte Helligkeit, der Radierer auf 0. Die FFT wird live neu berechnet. Das bearbeitete Bild wird zur neuen Filterquelle.
  • Spektrum: Der Pinsel hebt |G| mindestens auf die gewählte Amplitude an; der Radierer entfernt Frequenzen. Vorhandene Phasen bleiben erhalten, neue Frequenzen starten mit Phase 0. Jede Änderung gilt auch für G(−f) = G(f)*.
  • Filter: Preset und Regler werden immer auf die aktuelle Filterquelle angewendet, nicht wiederholt auf das bereits gefilterte Ergebnis. „Spektrum wiederherstellen“ zeigt die ungefilterte Quelle.
  • Skalen: r ist relativ zur axialen Nyquist-Frequenz (r = 1 entspräche 0,5 Zyklen/Pixel). Die Amplitude ist |G| / 256². Die Log-Anzeige verwendet eine feste Skala, sodass entfernte Frequenzen wirklich dunkler werden.
  • Bildanzeige: Automatischer Kontrast bildet das aktuelle Minimum und Maximum auf Schwarz und Weiß ab. Ohne Automatik wird nur die Anzeige auf [0, 1] begrenzt; negative Werte und Ringing bleiben intern erhalten. Die FFT nimmt periodische Bildränder an.
  • Tastatur: B = Pinsel, E = Radierer, S = fftshift, R = Reset, Strg/Cmd+Z = Rückgängig. Fokussierte Regler lassen sich mit Pfeiltasten bedienen.
