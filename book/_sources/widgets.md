# Interactive Widgets

This page provides an overview of the interactive widgets currently available with the course notes. Select a widget to open it in a new page.

## Image formation and optical systems

- <a href="widgets/2.1%20PSF%20-%20MTF%20Doppelansicht/index.html" target="_blank" rel="noopener noreferrer">PSF and MTF — dual view</a> — Explore a point spread function and its modulation transfer function side by side.
- <a href="widgets/2.2%20Thin%20lens%20Sandbox/thin-lens-sandbox.html" target="_blank" rel="noopener noreferrer">Thin lens sandbox</a> — Experiment with image formation using a thin lens.
- <a href="widgets/2.3%20Generischer%20Bilderfolgen-Stepper/index.html" target="_blank" rel="noopener noreferrer">Image sequence stepper</a> — Step through an image sequence or load your own images.
- <a href="widgets/2.4%20Faltungs-Scrubber/index.html" target="_blank" rel="noopener noreferrer">Convolution scrubber</a> — Explore the convolution operation interactively.
- <a href="widgets/2.5%202D-FFT-Malkasten/index.html" target="_blank" rel="noopener noreferrer">2D FFT drawing tool</a> — Draw a 2D signal and inspect its Fourier transform.
- <a href="widgets/2.8%20Dirac-Approximation%20und%20Fourier-Reihe/index.html" target="_blank" rel="noopener noreferrer">Dirac approximation and Fourier series</a> — Explore the Dirac approximation and its Fourier-series representation.
- <a href="widgets/2.9%20DFT%20und%20zyklische%20Fortsetzung/index.html" target="_blank" rel="noopener noreferrer">DFT and cyclic extension</a> — Explore periodicity, leakage, zero-padding, and 2D convolution with padding.
- <a href="widgets/2.10%20Fresnel-Linse/index.html" target="_blank" rel="noopener noreferrer">How a Fresnel lens is constructed</a> — Follow the construction of a refractive Fresnel lens.

## Light fields and directional imaging

- <a href="widgets/3.1%20Lichtfeld-Explorer/index.html" target="_blank" rel="noopener noreferrer">Light field explorer</a> — Inspect microlens-array measurements, sub-aperture views, and digital refocusing.
- <a href="widgets/3.2%20Lichtfeld-Ray-Diagramm/index.html" target="_blank" rel="noopener noreferrer">Camera light field and ray diagram</a> — Connect camera rays to light-field integration and virtual refocusing.
- <a href="widgets/3.3%20Zentralpixel-Detektion/index.html" target="_blank" rel="noopener noreferrer">Central display pixel detection</a> — Simulate coded measurements and recover central display-pixel positions.
- <a href="widgets/3.4%20Schlieren-Winkelfilter/index.html" target="_blank" rel="noopener noreferrer">Schlieren and angular filter</a> — Explore how an angular filter converts ray deflections into image brightness.
